# Machine Learning Techniques (Synthetic Demo Data)

Supervised learning uses labelled datasets to train models for classification and regression tasks.
Unsupervised learning discovers hidden patterns and groups in data without predefined labels.
Reinforcement learning trains agents through rewards and penalties based on their actions.
Decision trees use structured rules to make predictions and support interpretable decisions.
Random forests combine multiple decision trees to improve prediction stability and reduce overfitting.
Model evaluation uses metrics such as accuracy, precision, recall and F1-score to measure performance.
