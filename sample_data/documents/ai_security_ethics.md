# AI Security and Ethics (Synthetic Demo Data)

AI security focuses on protecting machine learning systems from malicious inputs and unauthorised access.
Data poisoning occurs when attackers manipulate training data to influence model behaviour.
Explainable AI helps users understand how automated systems produce predictions and decisions.
Human oversight is important when AI systems support high-impact decisions.
Responsible AI development requires privacy protection, fairness, accountability and transparency.
Regular testing and monitoring help identify model errors, security weaknesses and unexpected behaviour.
